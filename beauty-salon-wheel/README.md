# «Колесо фортуны» в директе Instagram

Клиент пишет в директ **КОЛЕСО**, и бот сразу отвечает:

> 🎡 Кручу колесо…
> 🎉 Тебе выпало: скидка 50%! Промокод WHEEL-7K2QX. Подарок действует 24 часа. Выбери день 👇
> [Сегодня] [Завтра] [На выходных]

Настроить это можно двумя способами. **Начните с варианта 1**: он проще.

---

## Вариант 1. Без кода, за 15 минут: ManyChat

ManyChat — официальный партнёр Instagram. Всё настраивается мышкой.

1. Зайдите на **manychat.com** и нажмите *Get Started*. Войдите через Instagram.
2. Откройте **Automation → New Automation → Start from scratch**.
3. **Триггер:** *Instagram → User sends a message*. Условие: сообщение содержит слово **КОЛЕСО**.
4. **Блок Message:** «Кручу колесо… 🎡». Прикрепите GIF с колесом.
5. **Блок Smart Delay:** 3 секунды.
6. **Блок Randomizer.** Сделайте 4 ветки и задайте проценты:
   - 40% → «Тебе выпало: скидка 20% 🎉»
   - 30% → «Тебе выпало: скидка 30% на маникюр 🎉»
   - 25% → «Тебе выпало: скидка 50% 🎉»
   - 5% → «Тебе выпало: бесплатный уход за кожей 🎉»
7. К каждому сообщению с призом добавьте **кнопку** «Записаться» со ссылкой на онлайн-запись.
8. Каждой ветке добавьте **тег** с названием приза (Actions → Add Tag). Так администратор увидит, кто что выиграл.
9. **Чтобы колесо крутили один раз:** в начале автоматизации поставьте **Condition**: «если у клиента уже есть тег приза → сообщение „Ты уже крутила колесо 😉“».
10. **Напоминание:** после приза поставьте Smart Delay на 20 часов и сообщение «⏳ Твой подарок сгорит через 4 часа!».
11. Нажмите **Set Live**.

Бесплатного тарифа ManyChat хватит, чтобы начать. Для тегов, условий и больших рассылок нужен тариф Pro.

## Вариант 2. Бесплатно на своём n8n

Используйте этот вариант, если у вас уже есть n8n. Бот делает то же, что в варианте 1, но без напоминания через 20 часов.

**Файл:** `2-direct-wheel-bot.workflow.json`

1. В n8n: **Workflows → Import from File** → выберите файл.
2. Откройте узел **⚙️ НАСТРОЙКИ — заполните** и впишите:
   - ссылку на GIF с колесом;
   - ссылку на онлайн-запись;
   - телефон салона.
3. Откройте узел **⚙️ Проверка Instagram — впишите свой пароль** и замените `salon2026` на своё слово.
4. Создайте учётные данные **Header Auth**: Name `Authorization`, Value `Bearer ВАШ_ТОКЕН_INSTAGRAM`. Выберите их во всех узлах, которые отправляют сообщения.
5. Включите воркфлоу (переключатель **Active**).
6. В **developers.facebook.com** откройте своё приложение → *Instagram → Webhooks*:
   - Callback URL — это *Production URL* узла «Сообщения из директа (POST)»;
   - Verify token — ваше слово из шага 3;
   - подпишитесь на `messages`.

**Призы** меняются в узле **«Крутим колесо»**. Число `weight` — это шанс в процентах.

## Автопостинг Reels (по желанию)

**Файл:** `1-content-autopilot.workflow.json`

Каждый день в 11:00 Claude пишет текст, Creatomate собирает ролик, и ролик выходит в Instagram.
Нужны ключ API Anthropic, аккаунт Creatomate с шаблоном (текстовые слои `Hook`, `Subtitle`, `CTA`) и токен Instagram.
Все значения вписываются в узел **⚙️ НАСТРОЙКИ — заполните**.

---

## Важно для Instagram

- Аккаунт должен быть **профессиональным** (Бизнес или Автор).
- Бот может писать клиенту только **24 часа** после его последнего сообщения. Поэтому напоминание в ManyChat ставьте не позже чем через 23 часа.
- В n8n бот запоминает, кто уже крутил колесо, только когда воркфлоу включён.
- Токен Instagram действует 60 дней. Потом его нужно обновить.
